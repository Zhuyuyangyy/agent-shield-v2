# AgentShield 成果说明

> **一句话定位**：V1 管 AI 说什么，V2 管 Agent 做什么；二者共同构成 AI Agent 的输出—行为双通道风险审计与熔断控制系统。

---

## 成果概述

AgentShield 是一套面向 AI Agent 的双通道风险审计与熔断控制系统，同时覆盖：

- **V1 输出侧审计**：幻觉检测、RAG 溯源、风险熵评分、硬门控、人工复核、审计留痕
- **V2 工具侧审计**：ToolCallRequest 标准化、数据库影子预演、数据资产敏感度映射、5 因子影子风险评分、三档熔断决策（block/human_review/allow）

---

## 核心创新表述

> **一种面向 AI Agent 的输出合规审计与工具调用影子预演熔断方法及系统**
>
> 通过输出侧审计（V1）和工具侧审计（V2）双通道融合，在 AI Agent"说什么"（输出）和"做什么"（工具调用）两个维度同时实现风险识别、预测和熔断控制，实现从"事后审计"到"事前防御"的技术跨越。

## 专利权利要求体系

**独立权利要求 2 项**：
1. 双通道审计与熔断控制方法（覆盖 V1+V2 全流程）
2. 实现所述方法的系统

**从属权利要求 13 项**，分别覆盖：
- 幻觉检测方法（引用覆盖率评分）
- 影子预演引擎（正则解析 + 表名推断兜底）
- 数据资产敏感度双层映射
- 外部传输意图检测（工具名模式匹配）
- 多因子加权评分模型（85%敏感数据权重）
- 三档熔断阈值定义（0.90 / 0.50）
- fail-safe 保守策略
- 影子偏差告警
- 双通道并行执行

## 竞争优势

| 优势 | 描述 |
|------|------|
| **事前防御** | 影子预演在执行前阻断，而非事后补救 |
| **双通道覆盖** | 同时控制 AI"说什么"和"做什么" |
| **可解释审计** | 每一次熔断都有完整的风险因子分解 |
| **fail-safe 保障** | 不可解释的调用默认阻断，不自动放行 |
| **轻量部署** | 影子预演无需真实数据库连接，零侵入 |
